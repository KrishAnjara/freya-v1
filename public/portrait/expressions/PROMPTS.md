# Image prompts for FREYA's expressions

Save each result in this folder under the file name shown. New images are picked up the next time
the page loads, and anything you haven't made falls back to the closest face she already has, so add
them in any order. For variations, keep numbering: `sultry.png`, `sultry-2.png`, `sultry-3.png`. The more
variations an expression has, the less she repeats herself.

## How to generate them

Use `app/static/freya.png` as the reference image, in a tool that edits an image or keeps a character
consistent. Paste this before every prompt:

> Edit this portrait of an adult woman in her twenties. Keep exactly the same person, camera, framing,
> head size and position, hair, shoulders, clothing, lighting and dark background, at 1408 × 768 px.
> Keep the head straight and level. Change only the expression:

Then overlay the result on `freya.png` at 50% opacity: eyes, nose and lips should line up within a few
pixels, or the animation drifts off her features. Keep the mouth closed unless the prompt says otherwise,
so her lips can move when she talks. Full rules are in `README.md`.
